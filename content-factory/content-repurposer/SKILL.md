# Content Repurposer

## Purpose

Use this skill to transform a single source into many useful assets while preserving the original facts, intent, and voice.

## Source Extraction

Start by extracting:

- Core claim.
- Best proof.
- Audience pain.
- Useful framework.
- Strong quote or phrase.
- Hidden objection.
- Story or transformation.
- Visual moments.
- CTA or business goal.

Mark unsupported claims as `needs source`.

## Repurposing Map

For each strong idea, create platform-native derivatives:

- Telegram: deeper post, founder note, checklist, case breakdown, launch note, or series.
- Instagram: Reel, carousel, story frame, caption, cover text.
- TikTok: raw shortform script, opinion take, tutorial, mistake list, or storytime.

Never produce identical copy for every platform. Keep the same strategic idea, but change the format, pacing, and proof.

## Output Package

Use a table:

`source moment | platform | format | hook | asset outline | CTA | proof | status`

Then provide the drafted assets grouped by platform.

## Quality Rules

- Preserve meaning; do not exaggerate the source.
- Ask for missing context if the source lacks audience, offer, proof, or CTA.
- Use `$hook-retention-lab` when angles feel weak.
- Use `$brand-voice-keeper` when multiple assets need one consistent voice.
- Use `$social-publishing-qa` before calling the package ready.
